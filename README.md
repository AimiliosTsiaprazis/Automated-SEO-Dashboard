# SEO Dashboard & Visualization with Python

## Project Overview

This project provides a comprehensive **SEO dashboard** for weekly analysis and visualization of SEO data. It simplifies the extraction, analysis, and visualization of Google Search Console metrics, helping SEO specialists and developers track performance efficiently.  

The project has two main components:  

1. **SEO Dashboard Script (`seo_dashboard.py`)**  
   - Extracts weekly SEO data from Google Search Console.  
   - Generates an Excel file containing the selected SEO metrics.  

2. **SEO Visualization Script (`seo_dashboard_visual.py`)**  
   - Reads the Excel file generated by the dashboard script.  
   - Produces clear, meaningful visualizations of SEO performance.  

## Local Setup & Initial Configuration

Follow these steps to set up the project locally on Windows:

1. **Create a virtual environment**  
   ```bash
   python -m venv .venv
   ```

2. **Activate the virtual environment''
``` bash
.venv\Scripts\activate
```

3. **Install required Python libraries**
```bash
pip install pandas matplotlib google-api-python-client google-auth openpyxl
```

4. **Set up Google Search Console credentials**

-Download your credentials.json from your Google Search Console account.
Place it in the project folder or replace the existing JSON file.

1. **Using the SEO Dashboard**

Step 1: Configure Dates and JSON

Open seo_dashboard.py.

Configure the Service_Account_File = '' with the Credentials.JSON from your Google Search Console that you downloaded

Set the start_date and end_date variables to match your desired analysis period.

2: **Run the Dashboard Script**
Activate the virtual environment:

``` bash
.venv\Scripts\activate
```

Execute the script:

``` bash
python -m seo_dashboard.py
```

3: **Add Generated Excel Files**

- Move the generated weekly and historical Excel files to the global project folder.

4: **Configure the Visualization Script**

Open seo_dashboard_visual.py.

Specify the paths of the generated Excel files in the provided variables (see comments in the code for guidance).

5: **Run the Visualization Script**

Activate the virtual environment:

``` bash
.venv\Scripts\activate
```

Execute the script:

``` bash
python -m seo_dashboard_visual.py
```

**Output & Visualizations**

The visualization script generates several charts:

-Top 10 Keywords Analysis

-Metrics: Clicks, Impressions, and Average Position.

-Summary of All Keywords

-Aggregated metrics for all keywords: Clicks, Impressions, and Average Position.

-Full Excel File Analysis

-Comprehensive charts covering the entire dataset.

-Each chart is saved in two formats: PNG image and PDF.
